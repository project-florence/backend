<h1 align="center">Florence API</h1>

<p align="center">
  <strong>The API server for the Florence platform</strong> — Market data collection, AI-assisted analysis, and virtual portfolio management.
</p>

---

Florence's API server collects market data such as BIST stocks, currency rates, precious metals, macroeconomic indicators, and the IPO calendar; analyzes news; and delivers AI-assisted reports and strategy simulations to all Florence applications.

## Features

- **Market Data Collection** — BIST stocks, currency rates, precious metals (gold, silver, platinum, palladium), macroeconomic indicators, and the IPO calendar
- **News Sentiment Analysis** — Sentiment analysis of news affecting the market
- **AI Reports** — Fundamental analysis, news sentiment, and strategy evaluation reports
- **Strategy Simulations** — Test strategies under different market scenarios
- **Virtual Portfolios** — Paper trading with commission accounting and XU100 benchmark
- **Watchlist and Favorites** — Add stocks to your watchlist and manage favorites
- **Data Export** — Google Takeout-style yearly data export
- **Credit System** — Free credits renewed daily
- **Bot Accounts** — Bot accounts for automated access
- **Secure Sign-in** — Account security with email verification

Detailed API documentation: [api-spec](https://github.com/project-florence/api-spec)

## Platforms

Access the Florence API through the web interface, desktop and mobile applications, as well as directly via the SDK.
