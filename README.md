Florence'ın API sunucusu; BIST hisse senetleri, döviz kurları, kıymetli metaller, makroekonomik göstergeler ve IPO takvimi gibi piyasa verilerini toplar, haberleri analiz eder ve yapay zekâ destekli raporlar ile strateji simülasyonlarını tüm Florence uygulamalarına sunar.

## Özellikler

- **Piyasa Verisi Toplama** — BIST hisseleri, döviz kurları, kıymetli metaller (altın, gümüş, platin, paladyum), makroekonomik göstergeler ve halka arz takvimi
- **Haber Duyarlılık Analizi** — Piyasayı etkileyen haberlerin duyarlılık analizi
- **Yapay Zekâ Raporları** — Temel analiz, haber duyarlılığı ve strateji değerlendirme raporları
- **Strateji Simülasyonları** — Farklı piyasa senaryolarında stratejilerin test edilmesi
- **Sanal Portföyler** — Komisyon muhasebesi ve XU100 kıyaslamasıyla deneme amaçlı yatırım
- **İzleme Listesi ve Favoriler** — Hisseleri izleme listenize ekleyin ve favorilerinizi yönetin
- **Veri Dışa Aktarma** — Google Takeout tarzı yıllık veri ihracatı
- **Kredi Sistemi** — Her gün yenilenen ücretsiz krediler
- **Bot Hesapları** — Otomatik erişim için bot hesapları
- **Güvenli Giriş** — E-posta doğrulamalı güvenli hesap erişimi

Detaylı API dokümantasyonu: [api-spec](https://github.com/project-florence/api-spec)

## Platformlar

Florence API'ye web arayüzü, masaüstü ve mobil uygulamaların yanı sıra SDK üzerinden de erişebilirsiniz.

## Repolar

- [web](https://github.com/project-florence/web) — Web arayüzü
- [desktop](https://github.com/project-florence/desktop) — Masaüstü uygulaması
- [mobile](https://github.com/project-florence/mobile) — Mobil uygulama
- [api-spec](https://github.com/project-florence/api-spec) — API spesifikasyonu ve referansları
- [florence-sdk](https://github.com/project-florence/florence-sdk) — Python SDK, CLI ve MCP sunucusu
